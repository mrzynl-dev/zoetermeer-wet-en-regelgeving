# Wet en regelgeving – Zoetermeer Roleplay

Dit is de officiële wet- en regelgeving website van **Zoetermeer Roleplay**.

Gebouwd met [MkDocs](https://www.mkdocs.org/) + Material theme.

## Lokaal draaien

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Open daarna http://127.0.0.1:8000

## Publiceren op GitHub Pages

Zie de uitleg in de chat / of push naar de `main` branch. De workflow publiceert automatisch.
